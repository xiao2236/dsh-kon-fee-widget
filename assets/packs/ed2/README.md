# 图包 ed2（素材待补）

把人物立绘按**同名文件**放进来即可自动生效：

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `table/mio.png` | 64×128 | 秋山澪 |
| `table/ritsu.png` | 80×128 | 田井中律 |
| `table/yui-frames.png` | 256×256（4×2 帧） | 平泽唯（帧表，想要动画就放这个） |
| `table/yui.png` | 64×128 | 平泽唯（只想要静态就放这个） |
| `table/tsumugi-frames.png` / `tsumugi.png` | 同上 | 琴吹䌷 |
| `table/azusa.png` | 64×128 | 中野梓 |
| `table/desk00.png` / `table/desk01.png` | 1152×160 / 288×160 | 想连桌子一起换才需要 |

规则：**只放你想改的文件**，没放的文件自动回退到原版；
放了帧表就播放动画，只放静态图则该角色变静态。
放好后刷新页面，设置页里这个图包就会从「待素材」变成可点。
